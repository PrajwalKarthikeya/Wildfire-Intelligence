# Phase 6 Journey Journal: The Risk Map

Machine learning probabilistic arrays mean absolutely nothing to a firefighter or an average citizen. Phase 6 is where the math becomes visual intelligence.

---

## 🧑‍🏫 Layman's Terms

We have a massive spreadsheet generated by our AI containing predictions for 440 different zones in California. Each zone has a score from `0.00` to `1.00`. 

We built a script that translates those robotic numbers into human language:
*   Less than 20%? **LOW** (Green)
*   20% to 40%? **MODERATE** (Yellow)
*   40% to 60%? **ELEVATED** (Orange)
*   60% to 80%? **HIGH** (Red)
*   Over 80%? **EXTREME** (Purple)

Then, we brought those colors to life on an interactive map. We used a tool called **Leaflet** to draw 440 colored squares across California. If you click on a square, a popup tells you the exact Risk Percentage, the current temperature, wind speed, humidity, and how many fires were recently detected there. 

It legitimately looks like a military radar screen.

---

## 👩‍💻 Technical Terms

### Step 1: Spatial Data Serialization
We needed to bridge the gap between our Python ML pipeline and our web frontend. 
*   **Action**: Created `generate_map_data.py`.
*   **Transformation**: The script reads the `california_risk_predictions.csv` inference output. It maps the continuous probabilistic target `[0, 1]` to five discrete categorical buckets, assigning distinct HEX color codes.
*   **Geometry Generation**: We mathematically synthesized bounding boxes for each spatial centroid (using our `0.5` degree grid step to calculate the vertices: `lon ± 0.25`, `lat ± 0.25`).
*   **Export**: Packaged the features and geometry into a standardized `GeoJSON` FeatureCollection (`data/risk_grid.geojson`).

### Step 2: The Map Prototype (Leaflet)
Before building the full React/Next.js dashboard (Phase 9), we rapidly prototyped the geospatial visualization layer.
*   **Action**: Authored a vanilla HTML/JS prototype (`frontend_prototype/map.html`).
*   **Stack**: Leveraged Leaflet.js over MapLibre GL for the MVP due to its simplicity in handling static GeoJSON files without requiring complex vector tile servers.
*   **Aesthetic**: Utilized CARTO's Dark Matter basemap to create a high-contrast, "intelligence platform" aesthetic that makes the colored risk polygons pop.
*   **Interactivity**: Programmed the `onEachFeature` hook to bind dynamic HTML popups displaying the underlying ML feature vector (`temperature`, `humidity`, `wind`, etc.) upon clicking a cell.

### The Result
We successfully transformed abstract ML probabilities into an actionable, interactive geospatial visualization. The local Python HTTP server is currently hosting it, completing Phase 6!
